# 반듯 (Bandeut)

> **허리는 펴고, 일은 계속.**
> 웹캠 하나로 앉은 자세를 지켜주는 온디바이스 자세 코치

반듯은 하루 종일 책상 앞에 앉아 일하는 사람을 위한 자세 교정 서비스입니다.
노트북에 이미 달려 있는 웹캠으로 자세를 실시간 분석하고, 무너지는 순간에만 조용히 개입하며,
틀어진 부위에 맞는 스트레칭까지 이어줍니다. **영상은 기기 밖으로 실시간 전송되지 않습니다.**

---

## 🪑 문제 — 우리는 하루 9.3시간을 앉아서 보냅니다

질병관리청 국민건강통계에 따르면 성인은 하루 평균 **9.3시간**을 앉아서 보냅니다.
그 시간 대부분, 우리는 자신의 자세를 인지하지 못합니다. 거북목과 디스크 질환은
한번 고착되면 되돌리는 데 큰 비용과 시간이 드는 현대인의 만성 질환이 되었습니다.

문제는 "바른 자세를 몰라서"가 아니라 — **무너지는 순간을 알아차리지 못해서**입니다.

## 💡 반듯의 답

| | |
|---|---|
| 👁 **알아차리게** | 웹캠이 2초마다 자세를 판정합니다. 나쁜 자세가 이어지는 순간, 그 자리에서 알려줍니다. |
| 🤫 **조용하게** | 평상시 존재감은 구석의 작은 위젯뿐. 무시할수록 위젯 → 토스트 → 전체 화면으로 개입이 세집니다. |
| 🔒 **내 기기에서만** | 자세 판정은 전부 브라우저 안(온디바이스)에서 처리됩니다. 하루 종일 켜두어도 영상이 서버로 흐르지 않습니다. |
| 🤸 **교정까지** | 거북목이 감지되면 턱 당기기를, 어깨 말림이 감지되면 가슴 열기를 — 감지와 스트레칭이 연결됩니다. |

## ✨ 주요 기능

### 1. 3초 캘리브레이션 — 나만의 기준 자세

바른 자세는 사람마다 다릅니다. 안내에 따라 바르게 앉아 3초만 유지하면,
그동안의 스켈레톤 좌표를 평균 내 **나만의 기준 자세**를 만듭니다.
어깨 수평·고개·목 조건을 실시간으로 체크해 바른 자세일 때만 캡처되고,
인체공학 권장 자세 가이드가 함께 제공됩니다.

### 2. 실시간 모니터링 — 6가지 지표로 판정

기준 자세 대비 **목 기울임(거북목) · 어깨 기울어짐 · 고개 숙임 · 화면 접근 · 뒤로 처짐 · 좌우 이탈**
6가지 편차를 계산해 자세 점수와 부위별(머리·어깨·상체) 상태를 보여줍니다.
민감도는 슬라이더로 조절할 수 있고, 잠깐의 움직임은 경고로 치지 않습니다.
5초 이상 자리를 비우면 자동으로 일시정지되고 카메라도 함께 꺼집니다.

### 3. 3단계 조용한 개입

- **1단계 · 위젯 신호** — 구석 위젯의 색과 실루엣만 조용히 바뀝니다. 업무 흐름을 끊지 않습니다.
- **2단계 · 토스트 (5초 지속 시)** — 무엇이 문제인지, 어떤 스트레칭으로 풀 수 있는지 콕 집어 알려줍니다.
- **3단계 · 전체 화면 (15초 지속 시, 옵트인)** — 그래도 안 고쳐지면 화면을 덮습니다. 고치기 전엔 일 못 합니다.

알림음(커스텀 사운드 포함)과 조용한 시간대 설정을 지원합니다.

### 4. 맞춤 스트레칭 — 감지가 처방으로

앉아서 하는 상반신 스트레칭 6종을 제공합니다. 감지된 자세 문제에 **가장 필요한 2가지**를 추천하고,
경고 알림에서 버튼 한 번으로 해당 동작 세션에 바로 진입합니다.

- **모션 가이드 애니메이션**: 정면(카메라 판정 기준)·측면(동작 원리) 두 각도로 시연
- **실시간 동작 판정**: 카메라 스켈레톤으로 각도·자세를 측정해, 올바르게 유지한 시간이 차면 자동 완료
- 시선·호흡처럼 그림으로 못 보여주는 항목은 체크포인트로 함께 안내

### 5. 자세 리포트

주 단위 캘린더에서 하루하루의 유지율을 한눈에 보고, 날짜를 누르면 시간대별 패턴과
경고 횟수, 시간당 평균 유지 시간을 확인할 수 있습니다. 모니터링을 종료하면
그날의 요약이 바로 뜨고, **AI가 하루 기록을 분석한 코멘트**가 리포트에 채워집니다.

### 6. 상시 미니 위젯

평상시의 반듯은 화면 구석 작은 위젯 하나가 전부입니다. 자세 상태를 색·실루엣·단계 도트로
표현하고, 클릭하면 미니 대시보드가 열립니다. 위젯 모드로 앱을 접어두어도 측정과 경고는
계속 동작합니다. (데스크톱 앱에서는 트레이 아이콘이 될 자리입니다)

## 🆚 무엇이 다른가

| | 반듯 | 기존 서비스들 |
|---|---|---|
| 기준 자세 | 개인별 캘리브레이션 + 바른 자세 검증 후 캡처 | 사용자가 보여준 자세를 그대로 기준으로 학습 (이미 거북목이면 그게 정상이 됨) |
| 감지 → 교정 | 감지된 부위에 맞는 스트레칭을 즉시 연결 | 감지만 하고 코칭 없음 |
| 프라이버시 | 판정 전부 온디바이스, 영상 실시간 전송 없음 | 서버 전송 또는 불투명 |
| 사용 환경 | 이미 쓰는 노트북 웹캠, 별도 장비 없음 | 별도 앱 설치(수백 MB), 폰 거치 필요 등 |
| 리포트 | 주간 캘린더 + 시간대 패턴 + AI 분석 코멘트 | 단순 점수 나열 |
